# GuildOfHeroes

Автор: Козубенко Елена
Дата выполнения: 22.10.2026


Добавлены методы:
- TakeDamage(int damage) - уменьшает здоровье на damage. Если здоровье становится отрицательным, то оно сбрасывается до 0.
- Heal(int amount) - восстанавливает amount здоровья.
- GainExperience(int amount) - повышает опыт на amount.
- IsAlive() - возвращает true, если здоровье больше 0, иначе false.
- GetInfo() - возвращает строку с информацией о герое.
